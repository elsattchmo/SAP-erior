# SAP-erior
SAP to SAP-erior Tool – Mine Site OT Swing Tracker & Handover.

**Live app:** https://elsattchmo.github.io/SAP-erior/

## Install on Android
1. Open the link above in **Chrome**.
2. Tap **⋮ → Add to Home screen** (or **Install app**).
3. Launch from the new icon – it runs full-screen and works offline once loaded.

Updates: push a new `index.html` to `main` – everyone gets it next time they open the app with signal.
Data is stored locally on each phone (browser storage), not on GitHub.
